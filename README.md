# سوق ماركت: منصة تجارة إلكترونية للسوبر ماركت (Next.js fullstack)

متجر على شكل أمازون (أقسام، بحث، ترتيب، صفحة منتج، سلة، طلب بالدفع عند الاستلام) + لوحة تحكم مرتبطة بنفس قاعدة البيانات. النسخة v3 تشمل صور منتجات حقيقية وواجهة مطوّرة.

## التشغيل محليًا
    npm install
    cp .env.example .env.local     # وغيّر ADMIN_PASSWORD و AUTH_SECRET
    npm run dev                    # http://localhost:3000
لوحة التحكم: /admin  (البريد وكلمة المرور من ملف البيئة)

## ماذا تتحكم من اللوحة
- الرئيسية: المبيعات، عدد الطلبات، رسم آخر 7 أيام، تنبيه المخزون
- الطلبات: تغيير الحالة (جديد، قيد التجهيز، في الطريق، تم التسليم، ملغي). الإلغاء يرجّع المخزون تلقائيًا
- المنتجات: إضافة وتعديل وحذف، السعر والخصم والمخزون ورابط الصورة والإخفاء والتمييز
- الإعدادات: اسم المتجر واللون والعملة والتوصيل وشريط العروض والأقسام وصورها (كل متجر لسوبر ماركت يتخصص من هنا بدون كود)

## النشر على دومين (VPS مثل Hetzner/DigitalOcean، أو أي سيرفر يشغّل Node 18+)
1. ارفع المشروع وشغّل: `npm install && npm run build`
2. أنشئ ملف `.env` بالقيم الحقيقية (ADMIN_PASSWORD قوية، AUTH_SECRET نص عشوائي طويل، DATA_DIR مثل /var/souq-data)
3. شغّل: `PORT=3000 npm start` (يُفضّل مع pm2: `pm2 start npm --name souq -- start`)
4. اضبط Nginx كـ reverse proxy للدومين إلى المنفذ 3000 وفعّل HTTPS (certbot)
5. وجّه سجل A للدومين إلى IP السيرفر

ملاحظة: Vercel لا يصلح كما هو لأن التخزين ملف JSON على القرص. على Vercel بدّل lib/db.js بقاعدة بيانات (Postgres/Supabase). باقي الكود لا يتغير.

## بيع المنصة لعدة محلات
كل عميل = نسخة منفصلة (دومين + DATA_DIR + ملف .env). غيّر الاسم واللون والأقسام من لوحة التحكم.

## حدود النسخة الحالية (للتطوير لاحقًا)
- التخزين ملف JSON (مناسب لمحل صغير/متوسط). للأحمال الكبيرة انقل لقاعدة بيانات
- دخول الأدمن حساب واحد؛ لا يوجد حسابات للعملاء ولا دفع أونلاين بعد
- صور المنتجات الحالية صور مخزنة داخل public/products؛ أي منتج جديد تضيفه من اللوحة يحتاج رابط صورة أو تظهر بطاقة لونية بأول حرف من اسمه

## صور المنتجات
الصور بتترفع من لوحة الإدارة (المنتجات ← منتج جديد/تعديل ← اختيار ملف). JPG/PNG/WEBP/GIF حتى 5 ميجا.
بتتخزن في `data/uploads` (أو `DATA_DIR/uploads`) وبتتعرض من `/api/uploads/...`. خُد نسخة احتياطية من فولدر `data` كله.

## تتبع الطلب والإشعارات (v6)
- بعد الطلب العميل بياخد رابط خاص بطلبه (فيه رمز سري)، وصفحة "طلباتي" في أعلى الموقع بتعرض كل طلباته من نفس المتصفح.
- لما الأدمن يغير الحالة، الموقع بيجيب التحديث كل ٢٠ ثانية ويظهر إشعار داخل الصفحة (وإشعار متصفح لو العميل فعّله). ده شغال بس والموقع مفتوح.
- في صفحة الطلبات بالأدمن زر "إبلاغ العميل واتساب" بيفتح رسالة جاهزة بالحالة الجديدة لإرسالها يدويا.
- الطلبات القديمة (قبل v6) ملهاش رمز فمش هتظهر للعملاء.

## تحسينات الشكل وتقارير المبيعات (v7)
- كاروسيل العروض: اختفى شريط التمرير، وفيه زرّين تنقل (السابق/التالي) على الكمبيوتر، وعلى الموبايل بالسحب.
- أيقونة الموقع (favicon) لوجو المتجر الأخضر، وعنوان التبويب: "اسم المتجر | سوبر ماركت أونلاين".
- القوائم المنسدلة (select) بشكل موحد بسهم مخصص بدل سهم المتصفح.
- صفحة جديدة في الأدمن: التقارير ← تقرير المبيعات اليومي: مبيعات اليوم، عدد الطلبات، الملغية، المتأخرة (أكتر من ٣ ساعات ولم تُسلَّم)، أكثر المنتجات مبيعاً، وجدول طلبات اليوم باسم العميل ورقم موبايله، مع اختيار أي يوم. الأيام محسوبة بتوقيت القاهرة.
